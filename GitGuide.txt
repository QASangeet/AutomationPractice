# M-1. Create GitHub Account: 
1. Go to browser and open "https://github.com/" URL.
2. Click on the "Sign up for GitHub" button. -> For doing registration.
3. We can register manually, by entering the Email, Password, Username(unique), checked the checkbox and click on the "Create Account" button 
or can be sign up through Gmail or Apple ID.
4. User will receive a verification code in Email or sometimes it may Puzzle.
>>> Account will be created successfully.

# M-2. Sign In to the GitHub
1. Enter the username/Email with password.
2. A verification code will trigger to the registered email address.
3. Fill verification code on the pop-up and signing in.
>> User signed in successfully.

# M-3. Create GitHub Repository: 
1. Click on the "Create Repository" button. -> The form will appear.
> Repository Name: AutomationPractice -->Singleword with camelCase will be prefer.
> Description: Same as above or can be modified.
> Choose visibility: Public
> Add READEME: On
> Add .gitignore: AL
> Click on the "Create Repository" button.
>> Repository will be created successfully.
