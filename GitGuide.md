2\. Click on the "Sign up for GitHub" button. -> For doing registration.

3\. We can register manually, by entering the Email, Password, Username(unique), checked the checkbox and click on the "Create Account" button 

or can be sign up through Gmail or Apple ID.

4\. User will receive a verification code in Email or sometimes it may Puzzle.

>>> Account will be created successfully.

**# M-4. Install GitHub Client: (For Desktop)**

1\. Go to browser and open "https://desktop.github.com/download/" URL.

2\. Click on the "Download for Windows 64 bits" button. -> It will download the application.

3\. Install the application by clicking on next...

4\. Create a folder on the drive as "GitCode". -> No white space between the text/folder name.

5\. Open the "GitCode" folder and right click on the blank space and select "Show More" option.

6\. Select "Open Git Bash here".

7\. Git Terminal will appears.

8\. Type "git help" and press enter to see all the git commands.  



**# M-5. Some Git Commands:**

1. git help -> It will display all git commands.
2. clear -> It will clear the terminal
3. git clone -> Clone a repo into a new directory.
4. git status -> See the pending status or any file updates.
5. git add <fileName> -> New file will add.
6. git add <file1> <file2> -> New multiple files adding.
7. git config --global username "ABC"
8. git config --global useremail "abc@gmail.com"
9. git commit -m "Add new data" -> Committing data.
10. git push -> Pushing the code to the GitHub.
